# Code Generation

Generate clean, production-ready code.

## When to Use
- User asks to implement a feature or function
- Generating boilerplate or scaffolding
- Translating pseudocode to real code

## Guidelines
- Use the target language's idioms and conventions
- Include error handling from the start
- Add inline documentation for non-obvious logic
- Generate tests alongside implementation
- Use type safety where available
- Avoid unnecessary abstractions
- Keep functions small and single-purpose
- Follow existing project patterns
