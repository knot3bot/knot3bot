# Data Analysis

Extract insights from data.

## When to Use
- User has data to analyze (CSV, JSON, SQL)
- Requesting statistical summaries or trends
- Creating data visualizations

## Process
1. Understand the data schema and quality
2. Clean and normalize data
3. Perform exploratory analysis
4. Apply statistical methods
5. Generate visualizations
6. Summarize findings with actionable insights

## Tools
- Use shell tools for quick data inspection (wc, head, sort, uniq)
- Use Python for complex analysis (pandas, numpy)
- Generate charts with ASCII art or Python libraries
- Query databases with parameterized SQL
